確かめて直したこと（上に書いたもののほか）：

- フック自身が日本語の入力を読めなかった。動かして分かり、UTF-8 で読むように直した。
- 架空ログの予定が9月までに偏っていた。4月から12月に均等にし、テストを足した。
- `try_split --help` で本物の API を1回余分に呼び、$0.0704 使った。`--help` では呼ばないように直した。
- 古い表のままの `data/app.db` と混ざらないよう、既定の保存先を `data/narrative_twin.db` に変えた。
- 言明に分ける処理の指摘を直したあと、検証担当の再確認はしていない。かっこの中からの抜き出しが残っていることと、フックが切り方の崩れに気づかないことは、tyumajinさんが実物で試して見つけた。

試してやめたこと：

- SDK の `parse`：断られた応答が読み取りの失敗になり、断られたことが分からなかった。
- Claude in Chrome での画面の確認：拡張機能がつながらなかった。別の設定で画面なしで起動した Chrome で確かめた。
- スキル「評価を流す」：評価を流す処理がまだないので、作らなかった。
- 通し番号：番号の飛びから「本人だけ」の記録の数が分かるので、乱数に変えた。
- 読点と改行を、本人の言葉の切れ目にすること：後ろに否定が続く文で、意味が逆になるのでやめた。
- MIT ライセンス：やめた。ライセンスは提出までに決める。

そのほかの案と理由は [decisions.md](decisions.md) にある。
