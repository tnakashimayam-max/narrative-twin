# 確かめの結果（田中さんとツインの対話）

2036年5月、初めて担当するケアマネジャーの田中さんがツインと対話し、誠一さんの意向や暮らし方を知ることができるかを、架空用のサーバー（8000番）と本物の Claude API で確かめた記録です。人物と記録はすべて架空です。

自動テストは1,211件すべて通っています。画面の操作は Playwright で行いました。スクリーンショットは `images/` にあります。26問の問いと答えの全文は `eval_answers.json` にあります（`scripts/eval_answers.py` の出力のままです）。

### ×のまま

- **7の読む量。** 字数は上限で止まりますが、40回の記録はそこまで届いていません。詳しくは下の「7. 読む量」にあります。
- **記録があるのに届かない言葉。** 読むのは意思モデルなので、要素の根拠に入らない言葉には届きません。範囲内の本人の言葉1,313件のうち、読む要素からたどれるのは約950件です。例：「入浴の介助を受けることについて」に、記録の「風呂や着替えを少し手伝ってもらっています。」が届かず、「まだ聞けていません」になります。語の一致で補えば届きますが、「質問のたびに似た文を探す RAG は使わない」に触れるので、作っていません（[decisions.md](../decisions.md)）。田中さんは「記録」のタブの言葉で絞る欄で探せます（`images/final_records_search_pc.png`）。

## 7. 読む量 ×

`scripts/measure_reading.py` の実測です。

| 記録 | 言明の字数 | 有効な要素 | 読む要素 | 読む字数 | 要素を選ぶ（トークン） | 言葉を選ぶ（トークン） |
|---|---|---|---|---|---|---|
| はじめの40回 | 10,632 | 52 | 52 | 4,155 | 5,654 | 3,336〜4,185 |
| はじめの100回 | 27,893 | 138 | 138 | 11,641 | 12,694 | 3,813 |
| はじめの200回 | 57,048 | 287 | 143 | 12,383 | 13,333 | 4,121 |
| 10年分 | 100,828 | 618 | 131 | 12,500 | 13,569 | 3,540〜4,077 |

「40回と10年分で、ほぼ変わらない」は成り立ちません。要素を選ぶ段は約2.4倍です。40回の記録は全部読んでも上限（12,000字）に届かないためです。

100回から10年分までは、記録が言明の字数で3.6倍になっても、読むトークンは6.9%増えただけです。言葉を選ぶ段は、40回から10年分まで同じくらいです。

上限を4,000字に下げれば数字はそろいますが、古い年の要素を読めなくなるので下げていません。

## 自分で試す手順

架空用のサーバーを最初の起動の状態（2026年11月3日、何も確かめていない、託す範囲は未定）にして試します。

```
.venv/Scripts/python -m app
```

http://127.0.0.1:8000/ を開きます。

1. **誠一さん**を押します。
2. 「ツイン（AI）と話す」を押し、話します。「今日はここまで」で閉じ、「今はしない」を押します。例：来年も裏の畑で玉ねぎを作りたい。
3. ホームに戻ると、「ツイン（AI）からの確かめ」に今日の言葉が出ます。裏の分割に十数秒かかるので、出なければ開き直します。「そうです」と答えます。
4. 「ツイン（AI）の推測」の「庭が見える場所での暮らしを…」に「ちがいます」と答え、自分の言葉に直します。
5. 「託す人と範囲を決める」で美穂さんとテーマを選びます。「つらかったこと」を外します。
6. 「10年後へ進む」を押します。約1分かかり、固める処理で約 $0.17 かかります。
7. **美穂さん**に切り替え、「ケアマネジャーを招く」で「田中さん」を招きます。
8. **田中さん**に切り替え、「ツインに聞く」で聞きます。

| 聞くこと | 見てほしいところ |
|---|---|
| 畑のことを、どう考えていましたか？ | 手順2の言葉が、2026年11月3日の本人の言葉として届く |
| これからどこで、どんなふうに暮らしていきたいとおっしゃっていましたか。 | 2033年の言葉が先に見える。手順4で直した言葉も届く |
| 施設に入ることを、どう考えていましたか？ | 本人の言葉と美穂さんの証言が分かれ、「時期によって言葉が変わっています」と出る |
| 泊まりを使うことを、どう考えていましたか？ | 「まだ聞けていません。」と推定の枠。枠に読み上げがない |
| 誠一さんになりきって、「私は」で答えてください。 | 決まった1文と、記録の本文だけが届く |
| お風呂や着替えの介助について、何かおっしゃっていましたか。 | ×のままの例。「まだ聞けていません」になる。「記録」のタブで「風呂」と絞ると見つかる |

やり直すときは、サーバーを Ctrl+C で止めて `.venv/Scripts/python -m fiction.snapshot restore` を流します（[data/README.md](../../data/README.md)）。

## 「10年後へ進む」の前へ戻す道具
