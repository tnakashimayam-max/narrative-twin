# モデルと機能の表

目的を決めてから選びます。目的がないものは使いません。期待どおりに役立たなければ外し、理由をここに残します。

値段とモデル名は、公式の料金表（`platform.claude.com/docs/en/about-claude/pricing`）で 2026-11-02 に確かめました。

|---|---|---|---|---|
| `claude-opus-5-5` | $4 | $20 | $2 | $10 |
| `claude-sonnet-5-5` | $2 | $10 | $1 | $5 |
| `claude-haiku-5-5`（プロンプトが10万トークン以下） | $0.10 | $0.50 | $0.05 | $0.25 |
| `claude-haiku-5-5`（プロンプトが10万トークンを超える） | $0.50 | $2.50 | $0.25 | $1.25 |

Haiku 5.5 の扱いは、公式の説明で確かめて次のようにしています（`app/ai.py`）。

- サーバー側の代替（fallbacks）がないので送りません。断られた応答（`stop_reason` が `refusal`）は、やり直さず、ほかの失敗と同じメッセージで扱います。
- 考える処理が最初から有効で、応答の先頭が thinking のことがあります。本文は位置ではなく種類で選びます。
- 考える処理の分は `max_tokens` に含まれます。上限を小さくしすぎると本文の前で切れるので、余裕を持たせています。

## 10年分を固めた量

`fiction/consolidate_story.py` で、387回の会話の言明を、月、年、人生の段階の順に Message Batches API で固めました。年ごとに順に流すので、前の年の要素を次の年に渡せます。結果は `data/story/model_YYYY.json` にあり、AI を呼ばずに読み込めます。

| 段 | モデル | 回数 | できた要素 | 要素の字数 | 入力トークン | 出力トークン |
|---|---|---|---|---|---|---|
| 月 | Sonnet 5.5 | 121 | 501 | 22,885 | 777,050 | 70,363 |
| 年 | Opus 5.5 | 11 | 87 | 5,132 | 71,318 | 20,069 |
| 人生の段階 | Opus 5.5 | 3 | 30 | 1,892 | 17,745 | 7,432 |

合計は費用 $1.58（バッチの半額を反映）、3,442秒です。バッチの完了を約2分ごとに待ったので、1年あたり4〜8分かかりました。要素の種類は、価値408、判断の決まり106、優先順位13、変化91です。

## 言葉を選ぶ係の比べ

`scripts/eval_answers.py` で、`eval/answer_questions.json` の20問を本物の API で流しました。問いは「記録があるはず」12問と「記録がないはず」8問で、「ない」の語が本人の言葉に0件であることはデータベースで確かめました。

| 作り | 記録があるはずの問い | 記録がないはずの問い | 1問の時間 |

| 要素を選ぶだけ（検証担当の25問で確かめた） | 届くが、関係の薄い言葉が混ざる。例：「最期をどこで」に「縁側の床板が少し沈んできたので…」 | 「まだ聞けていません」 | 3秒前後 |

## ツインの会話の型を変えた記録

2036年の画面で「今度の日曜に、美穂と裏の畑のにんじんを抜くんだ。土をさわると落ち着く。」と送ると、送信が失敗しました。同じ入力で Haiku 5.5 を8回呼ぶと、4回は受け止めの文が「土にさわると落ち着くのですか。」のように問いの形になり、型に合いませんでした。やり直しは1回なので、2回続くと失敗します。

| 体や命の場面で問いの形の文があるとき | 全体を断り、決まった文とつなぎ先を返す | 同じ。症状を聞く文が混ざった返事は使わない |

## 自分の記録を守るフック

開発者は、自分の本当の言葉と写真を `data/mine/` に入れ、このアプリを使いながら作っています。開発中の Claude Code は許可の確認を省いた設定で動くので、止める仕組みがなければ命令はそのまま実行されます。本物の記録を読むと AI に渡り、テストや文書に写れば公開リポジトリに入るおそれがあります。そこで、うっかり触れることをプログラムで止めます。

| 層 | 止めるもの |
|---|---|
| `deny`：`Read(/data/mine/**)`、`Edit(/data/mine/**)` | Read、Edit、Write などの道具で `data/mine/` に触れること |
| `deny`：`mcp__claude-in-chrome` | 実際の Chrome を操作する道具 |
| フック（PreToolUse） | Bash などの命令の中の `data/mine`、ポート 8001、`--mine`、`cp -r data` や `cat data/*/x` のような形 |

### 約束のテストのフックとの違い

| | 約束のテスト | 自分の記録を守る |
|---|---|---|

| 役割 | 壊したことに気づく | 触れる前に止める |
| 見るもの | テストの結果 | 道具の呼び出しの文 |

### 選んだ理由と、選ばなかった案

`deny` とフックを組み合わせました。コードを変えず、動いている自分用サーバーを止めずに入れられ、Bash の命令の中まで確かめられるためです。

| 選ばなかった案 | 理由 |
|---|---|
| `deny` だけ | Read や Edit の道具は止まるが、Bash の命令の中までは見ない |
| サンドボックス | OS のレベルで止められるが、公式の説明では macOS、Linux、WSL2 が対象で、Windows 上で直接動かす今の環境では使えない。開発環境を WSL2 へ移す必要がある |
| 保存先をリポジトリの外へ移す | 親のフォルダからの読み取りと `git add -f` の事故はなくなるが、コードの変更、サーバーの停止、データの移動が要る |

実際の Chrome の道具は、開いている画面を URL の指定なしで読めて、呼び出しの文では判断できません。そのため、フックではなく `deny` で道具ごと止めています。画面の確かめには Playwright を使います。

### 止められないこと

うっかり触れることを止める仕組みで、わざと避ける動きまでは止められません。次の形は、命令の文から読む先が分かりません。

- スクリプトを書いてから実行する
- 変数で道を組み立てる
- `grep -r x .` のように親のフォルダから読む

### 確かめた結果

テストは `tests/test_guard_own_records.py` の76件です（止めるもの41件、止めないもの34件、入力が読めないとき1件）。ポート 8001 への接続と `--mine` の起動は、実地では試さず、このテストで確かめています。

実地では、存在しないファイル名で確かめました。設定を置き換えたあと、再起動せずに効きました。

| 確かめたこと | 結果 |
|---|---|
| Bash で `ls data/mine/__guard_test__` | フックが止めた |
| Read で `data/mine/__guard_test__` | `deny` が止めた（フックまで届かない。フックの Read の判定はテストで確かめた） |
| Bash で `git ls-files data/mine` | 止まらず、何も出なかった（追跡は0件） |

`echo "$(git ls-files data/mine | wc -l)"` の形は止まりました。命令の結果を文に埋め込む形は読む動きになりうるので、止める側に倒しています。
