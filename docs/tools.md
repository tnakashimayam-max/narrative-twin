Haiku 5.5 の扱いは、公式の説明で確かめて次のようにしています（`app/ai.py`）。

- サーバー側の代替（fallbacks）がないので送りません。断られた応答（`stop_reason` が `refusal`）は、やり直さず、ほかの失敗と同じメッセージで扱います。
- 考える処理が最初から有効で、応答の先頭が thinking のことがあります。本文は位置ではなく種類で選びます。
- 考える処理の分は `max_tokens` に含まれます。上限を小さくしすぎると本文の前で切れるので、余裕を持たせています。

## 10年分を固めた量

`fiction/consolidate_story.py` で、387回の会話の言明を、月、年、人生の段階の順に Message Batches API で固めました。年ごとに順に流すので、前の年の要素を次の年に渡せます。結果は `data/story/model_YYYY.json` にあり、AI を呼ばずに読み込めます。

| 段 | モデル | 回数 | できた要素 | 要素の字数 | 入力トークン | 出力トークン |
|---|---|---|---|---|---|---|
| 月 | Sonnet 5.5 | 121 | 501 | 22,885 | 777,050 | 70,363 |

### この比べで言えないこと

- RAG 一般との比べではありません。2文字組の BM25 に、今の方式と同じ選ぶ係を付けたものです。ベクトル検索はしていません。今の方式も、選ばれた要素の根拠の中では2文字組で並べています（`app/advocacy.py` の `_closeness`）。
- 記録は架空の1人で、Haiku 5.5 が作ったものです。問いは84問で、数問の差は揺れの中です。
- BM25 は手を入れていない形です。問いの定型句（「どう話していましたか」など）を外していないので、短い文が上位に来ます。外すと、上位30件に入る正解は27.3%から30.2%に上がります（`scripts/compare_rag.py` の `probe`。AI を呼びません）。もとにした言葉が上位30件に入るのは、語を変えた38問で0問から1問になるだけです。同じ本文が候補に重なることもあります。
- 正解も目隠しの判定も Claude が付けたものです。広い問いの正解は揺れます。人は確かめていません。
- 読む量の伸びは比べていません。どの腕も候補の数を上限で切っています。今の方式の読む量は上の「田中さんのチャットの量」にあります。
- 変化の知らせ、ツインの色、推定意思など、意思モデルのほかの働きは比べていません。ケアとして正しいかにも触れていません。

## 自分の記録を守るフック

開発者は、自分の本当の言葉と写真を `data/mine/` に入れ、このアプリを使いながら作っています。開発中の Claude Code は許可の確認を省いた設定で動くので、止める仕組みがなければ命令はそのまま実行されます。本物の記録を読むと AI に渡り、テストや文書に写れば公開リポジトリに入るおそれがあります。そこで、うっかり触れることをプログラムで止めます。

| 層 | 止めるもの |
|---|---|
| `deny`：`Read(/data/mine/**)`、`Edit(/data/mine/**)` | Read、Edit、Write などの道具で `data/mine/` に触れること |
| `deny`：`mcp__claude-in-chrome` | 実際の Chrome を操作する道具 |
| フック（PreToolUse） | Bash などの命令の中の `data/mine`、ポート 8001、`--mine`、`cp -r data` や `cat data/*/x` のような形 |

### 約束のテストのフックとの違い

| | 約束のテスト | 自分の記録を守る |
|---|---|---|
| 動く時 | 編集のあと | 道具を使う前 |
| 役割 | 壊したことに気づく | 触れる前に止める |
| 見るもの | テストの結果 | 道具の呼び出しの文 |

### 選んだ理由と、選ばなかった案

`deny` とフックを組み合わせました。コードを変えず、動いている自分用サーバーを止めずに入れられ、Bash の命令の中まで確かめられるためです。

| 選ばなかった案 | 理由 |
|---|---|
| `deny` だけ | Read や Edit の道具は止まるが、Bash の命令の中までは見ない |
| サンドボックス | OS のレベルで止められるが、公式の説明では macOS、Linux、WSL2 が対象で、Windows 上で直接動かす今の環境では使えない。開発環境を WSL2 へ移す必要がある |
| 保存先をリポジトリの外へ移す | 親のフォルダからの読み取りと `git add -f` の事故はなくなるが、コードの変更、サーバーの停止、データの移動が要る |

実際の Chrome の道具は、開いている画面を URL の指定なしで読めて、呼び出しの文では判断できません。そのため、フックではなく `deny` で道具ごと止めています。画面の確かめには Playwright を使います。

### 止められないこと

うっかり触れることを止める仕組みで、わざと避ける動きまでは止められません。次の形は、命令の文から読む先が分かりません。

- スクリプトを書いてから実行する
