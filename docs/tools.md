# モデルと機能の表

目的を決めてから選びます。目的がないものは使いません。期待どおりに役立たなければ外し、理由をここに残します。

値段とモデル名は、公式の料金表（`platform.claude.com/docs/en/about-claude/pricing`）で 2026-11-02 に確かめました。

| モデル | 入力（1M トークン） | 出力（1M トークン） | バッチの入力 | バッチの出力 |
|---|---|---|---|---|
| `claude-opus-5-5` | $4 | $20 | $2 | $10 |
| `claude-sonnet-5-5` | $2 | $10 | $1 | $5 |
| `claude-haiku-5-5`（プロンプトが10万トークン以下） | $0.10 | $0.50 | $0.05 | $0.25 |
| `claude-haiku-5-5`（プロンプトが10万トークンを超える） | $0.50 | $2.50 | $0.25 | $1.25 |

Haiku 5.5 の扱いは、公式の説明で確かめて次のようにしています（`app/ai.py`）。

- サーバー側の代替（fallbacks）がないので送りません。断られた応答（`stop_reason` が `refusal`）は、やり直さず、ほかの失敗と同じメッセージで扱います。
- 考える処理が最初から有効で、応答の先頭が thinking のことがあります。本文は位置ではなく種類で選びます。
- 考える処理の分は `max_tokens` に含まれます。上限を小さくしすぎると本文の前で切れるので、余裕を持たせています。

|---|---|---|---|---|

## 言明への分割の比べ（Haiku 5.5 と Sonnet 5.5）

`eval/smoke_conversations.json` の架空の3つの会話を、同じプロンプトと同じ考える深さ（medium）で分けました（`scripts/compare_split.py`）。結果は Haiku のまま使います。

| 比べたこと | Haiku 5.5 | Sonnet 5.5 |
|---|---|---|
| 費用（3つの合計） | $0.0059 | $0.0683 |
| 時間（3つの合計） | 39.0秒 | 23.2秒 |
| 入力／出力トークン | 14,428／8,911 | 14,428／3,948 |
| 入らなかった言明 | 0件 | 0件 |
| 言明の数 | 10件 | 10件 |
| 拾えなかった発言 | 1件。「夏休みに、父と縁側でスイカを食べました。」を言明にしなかった | なし |
| 確かめる問いの候補 | 2件 | 1件 |
| 解釈の言い切り | 混ざる。「仕事で積み重ねてきた経験を大切に思っている。」 | ほぼ「〜かもしれません」で揃う |
| 本人の真意の慎重さ | 本人の真意を言い切り気味に読み、確からしさも 0.7 まである | 「この言葉だけでは分かりません」「本人の発言がないため、父の真意はわかりません」と書く |
| 視点の使い分け | ほぼ本人の視点だけ | 本当のニーズを専門職の視点で書くなど、分けている |

- Haiku は考える処理が多く出力トークンが増えたので、この3つでは Sonnet より時間がかかりました。裏で流す処理なので、本人は待ちません。
- 解釈はどちらも仮説として保存し、本人が確かめるまで確定しません。本人の言葉の一字一句はプログラムが確かめるので、モデルによる差はありません。
- この比べのあとで、プロンプトに「拾うこと」と「解釈の言い切り」の決まりを足しました。足したあとの比べはしていません。
