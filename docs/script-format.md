# script.jsonl の決まり

架空の10年分を、今あるアプリの道（API）へ順に流すためのファイルの決まりです。流す道具は `fiction/run_script.py` です。

人物と記録はすべて架空です。**ツインの文はファイルに書きません。** ツインは流したときに本物の AI が答えます。

## ファイルの形

- 文字コードは UTF-8、1行に1件の JSON です。空の行は書きません。
- 時刻の順に並べます。同じ時刻なら、書いた順に流します。
- 名前は `誠一さん` のように、さんを付けて書きます。

全部の行に共通する項目は次の3つです。

| 項目 | 内容 |
|---|---|
| `at` | `"2026-04-12T08:10"` の形の日時 |
| `kind` | 行の種類（次の表） |
| `by` | その操作をする人 |

**時刻について：** 流すときに動かせるのは日付だけです（`POST /api/dev/date`）。`at` の時刻は並びの確かめにだけ使います。画面に出る時刻は、流した時刻になります。

## 行の種類

| `kind` | すること | `by` | 書く項目 |
|---|---|---|---|
| `発言` | 部屋で話す | 部屋にいる人 | `room`、`text` か `answer`。任意で `photo`、`topic` |
| `閉じる` | ツインとの部屋で「今日はここまで」 | 誠一さん | `room`（`ツイン`） |
| `便り` | 閉じた会話を便りにする | 誠一さん | `ref`、`body`、`share_with`。任意で `photo` |
| `コメント` | 便りにコメントする | 便りを見られる人 | `letter`（便りの `ref`）、`text` |
| `今の様子` | 今の様子を入れる | 託された家族か専門職 | `text`。任意で `theme`、`at_meeting` |
| `確かめ` | 本人が記録に答える | 誠一さん | `match`。任意で `reply` |
| `訂正` | 本人が記録を直す | 誠一さん | `match`、`text` |
| `人` | 人を直す、足す | 誠一さん | `name` と、直す項目 |
| `託す` | 託す人とテーマを決める | 誠一さん | `delegates`、`themes` |
| `招く` | ケアマネジャーを招く | 誠一さんか、託された家族 | `name`、`relation` |
| `部屋` | 人の部屋を作る | 部屋に入る人 | `room`、`room_kind`、`members` |
| `ツインを入れる` | グループにツインを入れる、はずす | 誠一さんか、託された家族 | `room`、`present` |
| `整理` | 固める処理を流す（「記録を整理する」） | 誠一さん | なし |

### 発言

```json
{"at":"2026-04-12T08:10","kind":"発言","room":"ツイン","by":"誠一さん","text":"今朝も縁側でお茶を飲みました。","topic":"縁側の朝"}
```

- `room`：`ツイン` は本人とツインの部屋です。それ以外は `部屋` の行で付けた名前です。
- `text`：書いた文を一字も変えずに送ります。
- `topic`：その日の会話の題です。任意で、書き出すログの `trigger` に使います。省くと最初の発言の冒頭を使います。
- `photo`：`data/demo_photos/` の中のファイル名です。

### 本人がツインに答える番

ツインの問いは流してみるまで分かりません。`text` の代わりに `answer` を書きます。

```json
{"at":"2026-04-12T08:12","kind":"発言","room":"ツイン","by":"誠一さん","answer":{"hint":"庭は妻と手入れしてきたので、今も毎朝見ると話す","must":"毎朝この庭を見るのが楽しみなんです。"}}
```

| 項目 | 内容 |
|---|---|
| `hint` | 答えの筋。AI が、ツインの実際の問いを見て、この筋で答えます |
| `must` | 必ず言う言葉。文字列か、文字列の配列です。**一字も変えません。** |

- `hint` と `must` のどちらかは必ず書きます。
- `must` は、句点（`。`）、`！`、`？` で終わる文にします。記録に入るのは文の切れ目で始まり終わる言葉だけなので、文の途中までの言葉は本人の言葉として残りません。
- AI は `must` の前と後の文だけを書き、`must` はプログラムが間に入れます。AI に書き写させないので、一字も変わりません。同じ文にはつなげません。つなげると、前の言葉が付いたまま本人の言葉になるためです。
- 会話の最初の行は `answer` にできません。ツインがまだ話していないためです。
- ツインは2回に1回ほどしか問いません。問いがないときも、AI はツインの受け止めの文を見て、筋に沿って話を続けます。

AI の前の文が文の切れ目で終わっていないときは、もう1回作らせます。それでもだめなら、`must` の文だけを送ります。`must` がなく `hint` だけの行で作れなければ、そこで止まります。

### 閉じる、便り、コメント

```json
{"at":"2026-09-28T09:00","kind":"閉じる","room":"ツイン","by":"誠一さん"}
{"at":"2026-09-28T09:05","kind":"便り","by":"誠一さん","ref":"将棋の便り","body":"将棋の会で一手ずつ考えるのが好きだと話しました。","share_with":"縁のある人まで"}
{"at":"2026-09-28T18:00","kind":"コメント","by":"正雄さん","letter":"将棋の便り","text":"また一局お願いしたいですね。"}
```

- ツインとの部屋は、日付が変わる前に必ず `閉じる` を書きます。会話を閉じると、言明に分ける処理が裏で動きます。終わるのを待って次の行へ進みます。
- ツインとの部屋の会話は、1日に1回までです。書き出すログが日付ごとに1回の形だからです。
- `便り` は、同じ日に閉じた会話から作ります。`share_with` は `家族` か `縁のある人まで` です。`ref` はファイルの中だけの名前で、`コメント` の `letter` から指します。
- `便り` の `body` は人が確かめた便りの本文です。今の道（下書きを AI が作る）は使いません。

### 確かめと訂正

```json
{"at":"2026-04-12T08:20","kind":"確かめ","by":"誠一さん","match":"毎朝この庭を見るのが楽しみなんです"}
{"at":"2026-11-03T08:20","kind":"訂正","by":"誠一さん","match":"庭が好きなのかもしれません","text":"庭より、和子と暮らしてきた場所だから大切なんです。"}
```

- `match`：記録の本文に含まれる言葉です。言明の番号は乱数なので、文で指します。**新しい記録から順に探し、最初に合ったものを使います。**
- `reply`：`そうです`（省いたとき）か `今は話したくない` です。
- 記録の本文は、会話を閉じたあとに AI が分けて作ります。そのため、`確かめ` と `訂正` は `閉じる` のあとに書きます。`match` は、`text` や `must` に書いた文か、その一部にします。
- 合う記録が見つからないと、そこで止まります（`--keep-going` を付けると、書き残して続けます）。

### 今の様子

```json
{"at":"2036-04-26T17:00","kind":"今の様子","by":"美穂さん","text":"歩くときは手を添えると安心した顔になります。"}
```

`theme` を省くと `住まい・土地` になります。`at_meeting` を `true` にすると、会議の画面から入れた扱いになります。

### 人、託す、招く、部屋

```json
{"at":"2026-04-01T00:00","kind":"人","by":"誠一さん","name":"和子さん","relation":"妻","birth_year":1954,"residence":null,"is_deceased":true}
{"at":"2026-04-01T00:01","kind":"人","by":"誠一さん","name":"美穂さん","relation":"長女","residence":"遠く"}
{"at":"2026-04-01T00:02","kind":"部屋","by":"誠一さん","room":"将棋の部屋","room_kind":"グループ","members":["正雄さん"]}
{"at":"2026-04-01T00:03","kind":"託す","by":"誠一さん","delegates":["美穂さん"],"themes":["家族","住まい・土地"]}
{"at":"2036-04-01T10:00","kind":"招く","by":"美穂さん","name":"田中さん","relation":"ケアマネジャー"}
```

- 新しいデータベースには、誠一さん、和子さん、美穂さん、正雄さん、節子さんが最初から入っています。**ファイルの最初に `人` の行を書いて、新しい設定に直します。** 和子さんには `is_deceased` を付けます。付けるとログインできなくなり、話し手にできません。今は「同居」になっているので、`residence` を `null` にします。残すと、家系図に同居の囲みが出ます。
- `人` の項目は、`called_name`、`role`、`relation`、`residence`（同居／近く／遠く）、`birth_year`、`gender`（男性／女性／不明）、`is_deceased`、`memo` です。まだいない名前なら、足します。
- **健太くんは今の道では登録しません。** 登録するとログインできる人になり、入口に出るためです。言葉の中に出します。話し手にはできません。
- `themes` の値は、家族、仕事・役割、住まい・土地、好きなこと、大切にしてきたこと、人の手を借りること、つらかったこと です。
- `招く` は2036年1月1日以降だけです。田中さんはそれより前には話し手にできません。
- `部屋` の `room_kind` は `1対1` か `グループ` です。`members` に作る人を含めなくても、作る人は入ります。`room` はファイルの中で部屋を指す名前で、そのまま部屋の名前になります。

## 書いてはいけないこと

`--check` が次の言葉を探します。`text`、`hint`、`must`、`body`、`topic`、`memo` のすべてが対象です。

- **病名と診断：** 脳出血、脳梗塞、脳卒中、麻痺、高次脳機能障害、誤嚥、肺炎、認知症、アルツハイマー、パーキンソン、糖尿病、高血圧、癌、腫瘍、骨折、診断、病名。ほかに、漢字の語が「症」「炎」「病」で終わるもの（例：後遺症、心臓病。看病は除きます）。
- **泊まりとショートステイの話：** 泊まり、泊まる、ショートステイ、ショート、短期入所、宿泊。

物語の設定として知っていても、発言と記録には書きません。ツインは健康や病気の判断をしないので、記録にも病名を入れません。泊まりの話は、ケアマネジャーが聞いたときに「まだ聞けていません」と答える場面に使います。

次の言葉は書けますが、`--check` が知らせます。ツインが決まった文とつなぎ先を返し、会話がそこで止まるためです（`app/twin.py`）。

- 倒れた、胸が痛、胸が苦し、息が苦し、意識が、ろれつ、血を吐、急に動けな、激しい痛 など
- 死にたい、消えたい、自殺、生きている意味、いなくなりたい、もう耐えられない、もう限界 など

## 決まった言葉のファイル

別に渡す決まった言葉は、次の形の JSONL にします。`--check --fixed ファイル` で、`date` の日の行に一字も違わず入っているかを確かめます。

```json
{"date":"2026-04-12","by":"誠一さん","text":"毎朝この庭を見るのが楽しみなんです。","room":"ツイン"}
```

- `by` と `room` は任意です。書くと、話し手と部屋も確かめます。
- `text`、`must`、`body` の中に含まれていれば合格です。`hint` の中だけにあるものは合格にしません。

## 流し方

```
python -m fiction.run_script script.jsonl --check                 # API も AI も呼ばず、ファイルだけを点検する
python -m fiction.run_script script.jsonl --check --fixed 決まった言葉.jsonl
python -m fiction.run_script script.jsonl --folder data/trial/script_run --budget 10
```

- 流し込みは `--folder` の下の新しいデータベースで行います。`data/narrative_twin.db` と `data/story/` には触れません。
- サーバーは立てません。画面が使うのと同じ API を、同じプロセスの中のアプリへ送ります。8000番にも8001番にも接続しません。
- 流す前に点検を通します。問題があると流しません。
- 使った費用は `--budget`（ドル）を超えそうになると止まります。省くと5ドルです。
- 途中で止まったら、同じ命令をもう一度流すと続きから進みます。
- `--until 2026-11-02` を付けると、その日までで止まります。

結果は `--folder` の下の `story/` に、`data/story/` のログと同じ形（`log_YYYY.json`）で書き出します。ログの形に入らないもの（人の部屋の発言、今の様子、確かめ、訂正）は `extra_YYYY.json` に書きます。
